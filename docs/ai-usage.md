# AI usage

AI tools assisted with drafting and refining implementation ideas and code. The team should review and be able to explain the page structure, responsive styling, client-side calculations, validation, expense planner, rule-based chatbot, voice APIs, and accessibility decisions.

BudgetBee is a local keyword-matching educational assistant with predefined responses. It does not call an AI service and does not provide personalized financial advice. No user financial data is transmitted to a server.
