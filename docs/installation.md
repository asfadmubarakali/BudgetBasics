# Installation

BudgetBasics is a static, browser-only learning demo built with HTML, CSS, and vanilla JavaScript. It needs no build step, database, paid API, or package installation.

1. Open `index.html` in a current browser, or serve this directory with a static web server.
2. Use a local server (for example, VS Code Live Server) for consistent browser speech recognition and local storage behavior.
3. Browser voice input requires compatible Web Speech API support and user permission. Typed chat works without it.

The expense planner and theme preference use localStorage on the current browser. Contact and feedback forms only validate and display a local demo confirmation; they do not submit or store form contents.
