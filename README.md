# BudgetBasics | NextGen BudgetBee

A student-focused budgeting and financial awareness demo by **NEX GEN CODERS**. Learn. Plan. Save. Grow.

## Run

Open `index.html` in a modern browser, or serve the folder with a static web server. There is no build step, backend, database, or API key. See [installation](docs/installation.md).

## Features

- Budgeting concepts, knowledge quiz, and needs versus wants practice
- 50/30/20 calculator and savings goal estimator with input validation
- Expense planner with add, edit, delete, category filter, search, and local browser persistence
- Expandable money mistake guides and visual learning gallery
- Rule-based BudgetBee chat with optional browser speech input and output
- Topic search, theme preference, client-side form validation, live clock, and simulated visitor counter
- Responsive layout, keyboard focus indicators, semantic labels, and reduced-motion support

## Privacy and educational use

This is not a bank or transaction service. Do not enter sensitive personal or financial information. There is no server or database. Expense examples and the theme preference remain in localStorage on the device; form contents are not sent or saved. The visitor counter is simulated. Calculators are educational estimates, and the 50/30/20 split is a flexible guideline.

## Project files

- `index.html` — semantic content and interactive UI

- `Nexgen.js` — calculators, planner, chat, voice, search, and form interactions
